# Каталог б/у автомобилей и будущая интеграция с CM Expert

Интеграция с CM Expert **ещё не подключена**. Сейчас используется демонстрационный ассортимент LADA. API, адрес выгрузки, авторизация и названия полей CM Expert не предполагаются: их нужно согласовать по реальному примеру выгрузки.

## Подготовленная схема

```text
Выгрузка CM Expert
  -> серверный адаптер полей и статусов (будущий этап)
  -> inventory/vehicles.json (нормализованный каталог)
  -> node scripts/build-inventory.mjs
  -> dist/data/vehicles.js
  -> каталог, вкладки, избранное, карточки и главная галерея
```

Готовая страница не обращается к CM Expert. Ключи и пароли не должны попадать в `dist/` или GitHub. Будущий адаптер работает на сервере либо в защищённой задаче синхронизации и передаёт только публичные сведения об автомобилях.

## Данные

Источник для редактирования: `inventory/vehicles.json`. Файл `dist/data/vehicles.js` генерируется автоматически; его не нужно редактировать вручную. Для обновления готового каталога:

```sh
node scripts/build-inventory.mjs
```

Можно передать путь к другому нормализованному JSON-файлу:

```sh
node scripts/build-inventory.mjs /absolute/path/to/normalized-inventory.json
```

Перед записью выполняется валидация. Ошибка, неизвестный статус или повторяющийся ID останавливают обновление, сохраняя предыдущий подготовленный каталог. Запись производится через временный файл и переименование.

Объект верхнего уровня: `schemaVersion: 1`, `isDemo`, `source`, `updatedAt`, `vehicles`.

| Поле автомобиля | Назначение |
| --- | --- |
| `id` | Постоянный ID объявления. При обновлении и перестановке карточек не меняется; на нём основано избранное. |
| `stockNumber` | Публичный номер объявления. |
| `brand`, `model` | Марка и модель. |
| `condition` | `used`. |
| `status` | `available`, `reserved` или `sold`. |
| `year`, `mileageKm`, `priceRub` | Числа: год, пробег в километрах, стоимость в рублях. |
| `body`, `fuel`, `transmission` | Кузов, топливо и коробка передач. |
| `image`, `imageAlt` | Локальный файл в `assets/` или HTTPS URL, а также описание фотографии. |
| `character`, `description` | Короткая подпись и описание автомобиля. |
| `featured`, `heroPosition` | Показывать ли в главной галерее и позиция кадрирования. В галерее используются первые три отмеченных автомобиля. |

## Статусы интерфейса

| Нормализованный статус | Вкладка | Действие |
| --- | --- | --- |
| `available` | В наличии | Обсудить этот автомобиль |
| `reserved` | В резерве | Подобрать похожий автомобиль |
| `sold` | Проданы | Архивная карточка, подобрать похожий автомобиль |

Это внутренние статусы сайта, а не утверждение о полях API CM Expert. Сопоставление со статусами реальной выгрузки будет добавлено в адаптер. Исчезновение записи из выгрузки не должно автоматически трактоваться как продажа без согласованного правила.

## Перед подключением реальных данных

Нужны пример и формат выгрузки, способ доступа, постоянный ID объявления, схема статусов и желаемая частота синхронизации. После проверки заменить демонстрационные фотографии, цены, пробег и статусы реальными, обновить `isDemo` и публичные уведомления о деморежиме. Синхронизация не должна публиковать неполную или некорректную выгрузку.
